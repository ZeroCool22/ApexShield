# ApexShield 1.0.0

Primera versión pública de ApexShield, el ofuscador de JavaScript para Windows desarrollado por ZeroCool22.

## Incluye

- Cuatro presets de ofuscación y controles personalizables.
- Transformaciones mediante AST con Babel, renombrado de identificadores y ocultación de cadenas.
- Aplanamiento de flujo de control, propiedades calculadas y código muerto.
- Editor de entrada y salida con copiado, descarga y ajuste de línea.
- Prueba rápida de lógica JavaScript en un Web Worker con límite de ejecución.
- Estadísticas de tiempo, tamaño y entropía.
- Autoguardado, restauración de sesión y recuperación nativa de la interfaz.
- Ícono AS personalizado y accesos directos corregidos en el instalador EXE.
- CLI para procesar archivos desde la terminal.

## Qué descargar

- **ApexShield_1.0.0_x64-setup.exe:** instalador recomendado para Windows x64.
- **ApexShield_1.0.0_windows-x64_portable.zip:** extraer y abrir ApexShield.exe, sin instalar la aplicación.
- **ApexShield_1.0.0_x64_en-US.msi:** instalador alternativo MSI.
- **SHA256SUMS.txt:** sumas de comprobación de las descargas.

La aplicación utiliza Microsoft Edge WebView2 Runtime. El instalador puede descargarlo si falta; la versión sin instalación requiere tenerlo disponible.
